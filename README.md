# Sharks Cove Contact Manager
Sharks Cove is a pretty aquatic themed contact manager built for COP 4331'S Small Project Assignment

**Some of our features include:**
- Login and Registration of user accounts
- Ability to add new contacts on per-user basis
- Ability to edit and delete those contacts
- Search that has partial-search capability to help you find your contacts easier
